Voice calling directly from a website

Want to call from a website on your laptop, desktop or phone? We Met uses browser-based audio calling, so you can talk with approved listeners without installing a native application.

How to call from a desktop or laptop

  1. Visit We Met using an up-to-date Chrome or Edge browser on Windows, Linux or macOS. Recent Safari versions are also supported where browser microphone features are available.
  2. Log in to your We Met account and allow browser microphone access when requested.
  3. Browse available listener profiles, choose a language and add wallet talk-time.
  4. Request a voice call with an online listener. Your call timer and wallet billing start after the audio connection is established.

Phone calls without downloading an app

On Android or iPhone, open the same official website in a browser that supports WebRTC audio and microphone access. You can use the website directly; installing the optional PWA shortcut is not necessary for calls. Your phone must have an internet connection and microphone permission enabled.

Microphone not working?

Make sure the website is accessed over HTTPS, your browser has permission to use the microphone and another program is not using your audio input exclusively. If the browser says WebRTC or microphone access is unsupported, switch to a current Chrome, Edge or Safari version. Corporate networks, firewalls or weak internet connections can sometimes prevent a call from connecting.

Is it free to make calls?

Downloading an app is unnecessary, but voice calls are not free: We Met uses prepaid wallet minutes and bills connected time. The platform shows wallet packs before payment. Visit talk-time pricing for more detail.

Ready for a real voice conversation?

Open We Met, choose an available listener and call from your browser. No separate app is needed. Prepaid talk-time applies.
