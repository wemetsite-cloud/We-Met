WE MET V4.1 — QUICK START

1. Reset the Supabase database password that was previously shared.
2. Extract this ZIP to a new folder.
3. Double-click SETUP_WINDOWS.bat.
4. Paste the new Supabase Session Pooler URI.
5. Choose new private admin and listener passwords.
6. Double-click START_WINDOWS.bat and test locally.
7. Double-click MAKE_SAFE_GITHUB_COPY_WINDOWS.bat.
8. Upload only the generated we-met-platform-github-safe folder to a PRIVATE GitHub repository.
9. In Render choose New > Blueprint and connect the repository.
10. Enter DATABASE_URL, ADMIN_PASSWORD and DEMO_EMPLOYEE_PASSWORD.
11. Deploy Blueprint.
